🛒 E-Commerce Sales & Customer Analytics

Project Overview

A complete data analytics project analyzing e-commerce transactions to identify revenue drivers, profitable categories, customer value, regional performance, payment behavior, and operational issues.

Business Questions

How much revenue and profit did the business generate?

Which categories and products drive revenue?

Which regions generate the most sales?

Who are the highest-value customers?

What is the repeat customer rate?

Which payment methods are most popular?

What are the cancellation and return rates?

How does average order value change over time?

Tech Stack

SQL — business analysis, aggregation, CTEs, window-style analytics

Python — Pandas, Matplotlib, exploratory analysis

Excel — optional management analysis and pivot tables

GitHub — project documentation and version control

Dataset

The included synthetic dataset contains 5,000 e-commerce order records, 1,500 customers and 120 products for 2025.
